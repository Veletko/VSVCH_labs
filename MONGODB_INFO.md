# 📊 Информация о MongoDB базе данных

## 🔌 Подключение к базе данных

**Строка подключения:**
```
mongodb://localhost:27017/Fuctory
```

**Имя базы данных:** `Fuctory` (⚠️ обратите внимание на опечатку - "Fuctory" вместо "Factory")

## 📁 Коллекции (таблицы) в базе данных

В вашей базе данных должно быть **5 коллекций**:

1. **`masters`** - Мастера
   - Хранит информацию о мастерах
   - Поля: `_id`, `last_name`, `first_name`, `middle_name`, `email`, `password_hash`, `role`, `is_active`, `workers[]`, `maintenance_history[]`

2. **`workers`** - Рабочие
   - Хранит информацию о рабочих
   - Поля: `_id`, `last_name`, `first_name`, `middle_name`, `master_id`

3. **`machines`** - Машины
   - Хранит информацию о машинах
   - Поля: `_id`, `status`, `maintenance_history[]`, `createdAt`, `updatedAt`

4. **`maintenance_histories`** - История обслуживания
   - Хранит записи об обслуживании машин
   - Поля: `_id`, `machine_id`, `master_id`, `state`, `start_date`, `end_date`

5. **`workshops`** - Цеха
   - Хранит схемы цехов с элементами (стены, двери, станки)
   - Поля: `_id`, `name`, `description`, `elements[]`, `canvasWidth`, `canvasHeight`, `createdAt`, `updatedAt`

## 🔍 Почему данные не видны в MongoDB Compass?

### Возможные причины:

1. **Неправильное подключение в Compass**
   - Убедитесь, что вы подключаетесь к: `mongodb://localhost:27017`
   - Выберите базу данных: `Fuctory` (не "Factory"!)

2. **Данные сохраняются в другую базу**
   - Проверьте переменную окружения `MONGODB_URI` в файле `.env`
   - Если `.env` не существует, используется база `Fuctory` по умолчанию

3. **MongoDB не запущен**
   - Убедитесь, что MongoDB запущен на порту 27017
   - Проверьте: `mongosh` или через Compass

4. **Коллекции создаются автоматически**
   - В MongoDB коллекции создаются автоматически при первой записи
   - Если вы добавили данные через приложение, они должны быть в базе

## ⚠️ О лишней таблице/миграции

### Лишний файл миграции:
В папке `backend/migrations/` есть файл **`001-initial-migration.js`**, который **НЕ используется** в текущей версии. Активные миграции:
- ✅ `001-create-tables.js` - создает коллекции
- ✅ `002-fix-ids.js` - исправляет ID
- ❌ `001-initial-migration.js` - **НЕ используется** (можно удалить)

### Лишняя коллекция в БД:

Если вы видите **5 коллекций** вместо 4, возможные причины:

1. **Старая база данных** - возможно, осталась коллекция из предыдущей версии
2. **Системная коллекция** - MongoDB создает служебные коллекции (например, для индексов)
3. **Тестовая коллекция** - возможно, была создана для тестирования
4. **Коллекция из старой миграции** - `001-initial-migration.js` могла создать лишнюю коллекцию

**Проверьте:**
- Откройте MongoDB Compass
- Посмотрите все коллекции в базе `Fuctory`
- Если есть лишняя коллекция, назовите её - я помогу определить, нужна ли она

**Нужные коллекции (4 штуки):**
- `masters`
- `workers`
- `machines`
- `maintenance_histories`

**Все остальные коллекции можно удалить** (если они не системные)

## 📝 Важные замечания

1. **Имя базы данных:** `Fuctory` (с опечаткой) - это используется в коде
2. **Автоматическое создание:** Коллекции создаются автоматически при первой записи
3. **Миграции:** Файл `001-create-tables.js` создает коллекции и индексы, но они также создаются автоматически
4. **Переменные окружения:** Проверьте файл `.env` в папке `backend/` - там может быть указана другая база данных

## 🔧 Как исправить подключение

Если данные не видны, проверьте:

1. **Файл `.env` в `backend/`** (если есть):
   ```
   MONGODB_URI=mongodb://localhost:27017/Fuctory
   ```

2. **Запущен ли MongoDB:**
   ```bash
   # Windows
   net start MongoDB
   
   # Linux/Mac
   sudo service mongod start
   ```

3. **Правильное имя базы в Compass:**
   - Должно быть: `Fuctory` (не `Factory`, не `factory`, не `Fuctory` с другой регистрацией)
