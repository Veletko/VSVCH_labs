# 🔄 Миграция базы данных

## Новая база данных

**Название:** `FactoryDB`

**Строка подключения:**
```
mongodb://localhost:27017/FactoryDB
```

## Как создать новую базу данных

1. **Остановите backend сервер** (если запущен)

2. **Запустите миграцию:**
   ```bash
   cd backend
   node migrations/migrate.js
   ```

3. **Перезапустите backend сервер:**
   ```bash
   node server.js
   ```

## Что будет создано

Миграция создаст новую базу данных `FactoryDB` со следующими коллекциями:

1. `masters` - Мастера
2. `workers` - Рабочие  
3. `machines` - Машины
4. `maintenance_histories` - История обслуживания
5. `workshops` - Цеха (новая коллекция для схем цехов)

## Важно

- Старая база данных `Fuctory` останется нетронутой в MongoDB
- Новая база данных `FactoryDB` будет создана с нуля
- Все данные нужно будет добавить заново или перенести из старой базы

## Переменная окружения

Если у вас есть файл `.env` в папке `backend/`, добавьте или обновите:

```
MONGODB_URI=mongodb://localhost:27017/FactoryDB
```

Если файла `.env` нет, база данных `FactoryDB` будет использоваться по умолчанию.
